  2. Перейдіть у Workers & Pages → Create → Create Worker
  3. Дайте ім'я (наприклад minfin-proxy) і натисніть Deploy
  4. Натисніть Edit Code, замініть весь код на наведений нижче (натисніть 📋 Копіювати)

// cloudflare.com Worker для обходу захисту CORS під час парсингу даних

export default {
  async fetch(request, env, ctx) {
    const corsHeaders = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET,HEAD,POST,OPTIONS',
      'Access-Control-Max-Age': '86400',
    };

    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: corsHeaders });
    }

    const url    = new URL(request.url);
    const bondId = url.searchParams.get('id');

    if (!bondId) {
      return new Response('Помилка: Не вказано параметр id',
        { status: 400, headers: corsHeaders });
    }

    if (!/^[a-zA-Z0-9]{5,20}$/.test(bondId)) {
      return new Response('Помилка: Недопустимий формат id',
        { status: 400, headers: corsHeaders });
    }

    const targetUrl =
      `https://index.minfin.com.ua/ua/finance/bonds/${bondId.toLowerCase()}/`;

    try {
      const response = await fetch(targetUrl, {
        headers: {
          'User-Agent':      'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
          'Accept':          'text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8',
          'Accept-Language': 'uk-UA,uk;q=0.9,en;q=0.8',
          'Accept-Encoding': 'identity',
          'Referer':         'https://index.minfin.com.ua/',
        }
      });

      const html = await response.text();

      return new Response(html, {
        status: response.status,
        headers: {
          ...corsHeaders,
          'Content-Type': 'text/html; charset=utf-8',
        }
      });

    } catch (error) {
      return new Response('Proxy Error: ' + error.message,
        { status: 500, headers: corsHeaders });
    }
  },
};

6. Додаткові можливості

Завантаження з Мінфіну

Для ОВДП: введіть ISIN → «Завантажити» → поля заповнюються автоматично. Потрібен проксі-сервер (налаштування в ⚙).

Автозавантаження курсів НБУ

Для валютних ОВДП курси завантажуються при першому розрахунку. Їх можна коригувати вручну.

Пов’язані особи

Перемикач для позик і зобов’язань: різниця між номіналом і справедливою вартістю — у власному капіталі (рах. 425) замість 977/733 (МСБО 24, НП(С)БО 23).

7. Налаштування

Кнопка ⚙ у заголовку: адреса проксі-сервера для завантаження даних ОВДП. Інструкція зі створення власного сервера. Зберігається у сховищі браузера.

8. Друк

Кнопка «Друк / PDF»: обидві вкладки (НП(С)БО та МСФЗ) друкуються на окремих сторінках. Для PDF оберіть «Зберегти як PDF» у діалозі друку.

9. Приклади

Безвідсоткова позика

  1. Тип → «Видана позика»
  2. Номінальна сума → 100 000, договірна ставка → 0, ринкова → 18
  3. Дата визнання → 01.01.2025, дата погашення → 01.01.2028
  4. Натисніть «Розрахувати»

Купонна ОВДП

  1. Тип → «ОВДП (гривнева)»
  2. Код ISIN → введіть, натисніть «Завантажити»
  3. Перевірте поля, введіть справедливу вартість НБУ
  4. Натисніть «Розрахувати», перемикайте вкладки НП(С)БО / МСФЗ

Оренда офісу

  1. Тип → «Оренда (МСФЗ 16)»
  2. Платіж → 15 000, щомісяця, на початку, ставка → 14
  3. Дата початку → 01.01.2025, закінчення → 31.12.2027 (36 місяців)
  4. Рахунки обліку → 531, 122, 136 (заповнюються автоматично)
  5. Натисніть «Розрахувати»

Кредит «5-7-9%»

  1. Тип → «Кредит «Доступні кредити 5-7-9%»»
  2. Сума → 1 000 000, пільгова ставка → 9%, базова банку → 16, ринкова для МСФЗ → 20
  3. Спосіб погашення → «Рівними частинами»
  4. Дата отримання → 01.01.2025, дата погашення → 01.01.2028
  5. Натисніть «Розрахувати»; перемикайте вкладки НП(С)БО / МСФЗ для порівняння
