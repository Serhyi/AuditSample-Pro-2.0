## 1. Призначення програми

**FinDiscounting Pro** — інструмент для дисконтування фінансових інструментів та розрахунку оренди.

Програма виконує:

- обчислення теперішньої вартості (ТВ) грошових потоків;
- визначення ефективної ставки відсотка (ЕСВ);
- побудову таблиць амортизації методом ефективної ставки;
- формування бухгалтерських проведень за НП(С)БО та МСФЗ;
- порівняння облікових підходів (НП(С)БО / МСФЗ 9) для ОВДП.

Файл працює автономно у браузері. Мережа потрібна лише для завантаження даних з Міністерства фінансів та курсів НБУ.

**Нормативна база:**
НП(С)БО 10, 11, 12, 13, 28 · МСФЗ 9, 16 · МСБО 32, 37, 39

### 3.1 Видана позика

**Категорія:** Фінансові активи

**Застосування.** Підприємство видало позику за ставкою нижче ринкової або безвідсотково. Різниця між номіналом і теперішньою вартістю визнається витратами (або внеском до капіталу пов'язаної особи).

#### Поля введення

| Поле | Призначення |
|---|---|
| Номінальна сума | Основна сума позики (тіло боргу) |
| Договірна ставка, % | Відсоткова ставка за договором. Для безвідсоткових — `0` |
| Ринкова / ефективна ставка, % | Ставка, за якою дисконтуються грошові потоки |
| Комісія при видачі | Включається до балансової вартості; змінює ЕСВ (НП(С)БО 12 п. 29, МСФЗ 9 В5.1.1) |
| Пов'язана особа | Перемикач. Змінює рахунки проведень: 424/425 замість 949/733 (МСБО 24, НП(С)БО 23) |

#### Рахунки обліку

183 · 377 · 14

#### Порядок розрахунку

1. Квартальні відсоткові платежі = Номінал × Договірна ставка / 4.
2. Теперішня вартість = сума дисконтованих грошових потоків за ринковою ставкою.
3. Дисконт = Номінал − ТВ.
4. Якщо комісія > 0 — ТВ збільшується, ЕСВ перераховується.

#### Проведення (НП(С)БО)

| Операція | Дт | Кт | Сума |
|---|---|---|---|
| Видача позики | Рахунок обліку | 311 | ТВ |
| Визнання дисконту | 949 (або 424) | Рахунок обліку | Дисконт |
| Комісія | Рахунок обліку | 685 | Комісія |
| Нарахування ЕСВ (щокварталу) | Рахунок обліку | 733 (або 425) | Відсотки |
| Переведення до поточної (≤ 12 міс.) | 183 / 377 | Довгостроковий рахунок | Залишок |
| Погашення | 311 | Рахунок обліку | Номінал |

**Автовизначення підтипу.** Якщо договірна ставка ≈ 0 — у позначці відображається «Видана позика — безвідсоткова». Якщо ставка > 0, але дисконт > 0,01 — «договірна X % (нижче ринку)».

### 3.2 Отримана позика (кредит)

**Категорія:** Фінансові зобов'язання

**Застосування.** Підприємство отримало позику або кредит за пільговою ставкою.

#### Поля введення

| Поле | Призначення |
|---|---|
| Номінальна сума | Сума зобов'язання до погашення |
| Договірна ставка кредиту, % | Ставка за кредитним договором |
| Ринкова ставка, % | Ставка для дисконтування |
| Комісія | Витрати на оформлення |
| Пов'язана особа | Перемикач (МСБО 24) |

#### Рахунки обліку

505 · 55 · 601

#### Особливості

- **Рекласифікація.** В останній рік перед погашенням автоматично формується проведення переведення з довгострокового рахунку на 611 «Поточна заборгованість за довгостроковими зобов'язаннями».
- **Погашення.** Через 611 → 311.
- Дисконт визнається як дохід (Кт 733 або 425).

### 3.3 Довгострокове зобов'язання

**Категорія:** Фінансові зобов'язання

**Застосування.** Довгострокова торговельна або інша заборгованість, що потребує дисконтування.

#### Поля введення

Аналогічні до отриманої позики: номінальна сума, договірна ставка зобов'язання, ринкова ставка, комісія, пов'язана особа.

#### Рахунки обліку

55 · 685 · 505

#### Відмінності від позики

- Рекласифікація до поточної частини не передбачена.
- Погашення — Дт рахунок / Кт 311 напряму.

### 3.5 ОВДП (гривнева)

**Категорія:** Фінансові активи

**Застосування.** Підприємство придбало облігації внутрішньої державної позики, номіновані в гривні.

Це найбільш розвинутий тип інструменту: окрема панель введення, завантаження даних з Міністерства фінансів, подвійний розрахунок за НП(С)БО та МСФЗ 9, графік купонних виплат.

#### Панель ОВДП — поля введення

| Поле | Призначення |
|---|---|
| Код ISIN | Міжнародний ідентифікатор облігації (напр., UA4000244163). Поруч — кнопка **«Завантажити»** |
| Номінал 1 облігації | Зазвичай 1 000 грн |
| Кількість, шт. | Кількість придбаних облігацій |
| Термін обігу, днів | Від дати емісії до дати погашення |
| Комісія при придбанні | Включається до балансової вартості (НП(С)БО 12 п. 29, МСФЗ 9 В5.1.1) |
| Купонна ставка, грн / 1 обл. | Сума купону за одну виплату. Для безкупонних (дисконтних) — `0` |
| Номінальна дохідність НБУ, % | Річна дохідність із реєстру Національного банку |
| Фактична ціна 1 обл. | Ціна придбання — основа для розрахунку ЕСВ за НП(С)БО |
| Справедлива вартість НБУ, грн / 1 обл. | З реєстру НБУ — основа для ЕСВ за МСФЗ 9. Якщо не заповнено — використовується фактична ціна |

#### Зведення (автоматичне)

Після заповнення полів відображається:
- загальний номінал (номінал × кількість);
- загальна сума придбання (ціна × кількість);
- комісія;
- ТВ з комісією (НП(С)БО / МСФЗ);
- дисконт або премія;
- тип (автовизначення): «з дисконтом» / «з премією» / «за номіналом».

#### Завантаження даних з Міністерства фінансів

1. Введіть код ISIN.
2. Натисніть **«Завантажити»** (або Enter у полі ISIN).
3. Програма через проксі-сервер звертається до `index.minfin.com.ua` та отримує: валюту, термін обігу, дохідність, купон, дату погашення, дату розміщення, графік купонних виплат.
4. Поля заповнюються автоматично. Якщо дати купонів не знайдено — з'являється блок ручного введення.

#### Ручне введення дат купонних виплат

Якщо автоматичний пошук не знайшов графіка (або потрібне коригування):
1. У блоці **«Дати купонних виплат (ручне введення)»** оберіть дату.
2. Натисніть **«＋ Додати»**.
3. Для видалення натисніть **✕** поруч із відповідною датою.

Дати автоматично перевіряються на дублювання та сортуються за хронологією.

#### Графік купонних виплат

Відображається після заповнення полів:
- номер виплати, дата, кількість днів від дати придбання, сума (купон × кількість облігацій);
- показуються лише виплати **після** дати придбання та **до** дати погашення.

#### Дві вкладки результатів: НП(С)БО та МСФЗ 9

Для ОВДП (на відміну від інших типів) результати подаються у **двох вкладках**:

| | НП(С)БО | МСФЗ 9 |
|---|---|---|
| **Основа для ЕСВ** | Фактична ціна придбання + комісія | Справедлива вартість НБУ + комісія |
| **Різниця першого дня** | Поглинається дисконтом / премією | Визнається у прибутках / збитках одразу |
| **Рахунок доходу ЕСВ** | 733 «Інші доходи від фінансових операцій» | 732 «Відсоткові доходи» |
| **Нормативна основа** | НП(С)БО 12, 13 | МСФЗ 9 п. 5.1.1, В5.1.1 |

**Різниця першого дня (МСФЗ 9).** Якщо фактична ціна відрізняється від справедливої вартості НБУ — різниця визнається одразу: збиток (Дт 977) або дохід (Кт 733). Амортизація за МСФЗ 9 будується від справедливої вартості з окремою ЕСВ.

#### Рахунки обліку

352 «Інші поточні фінансові інвестиції» · 143 «Інвестиції пов'язаним сторонам»

#### Безкупонні (дисконтні) ОВДП

Якщо купон = 0:
- автоматично розраховується дисконтована ціна: P = N / (1 + y × d / 365);
- єдиний грошовий потік — повернення номіналу на дату погашення;
- купонні дати не використовуються.

### 3.6 ОВДП (валютна)

**Категорія:** Фінансові активи

**Застосування.** Підприємство придбало ОВДП, номіновані в іноземній валюті (долар США або євро).

#### Відмінності від гривневої ОВДП

Усе як для гривневої ОВДП, плюс додаткові поля:

| Поле | Призначення |
|---|---|
| Валюта ОВДП | Вибір: долар США або євро |
| Курс НБУ на дату придбання | Офіційний курс перерахунку, грн / валюта |
| Номінал у гривнях | Автоматично: номінал × кількість × курс |

#### Перемикач «Гривнева / Валютна»

Кнопка-перемикач праворуч від заголовка «ОВДП» дозволяє швидко переключитися між гривневим та валютним режимом без втрати введених даних.

#### Розклад курсів НБУ по датах

Після першого розрахунку з'являється блок **«Курси НБУ по датах»**:

- для кожної дати часової шкали (придбання, звітні дати, купони, погашення) — окреме поле з курсом;
- кнопка **«Оновити курси НБУ»** — автоматичне завантаження офіційних курсів НБУ;
- кнопка **«Перерахувати»** — оновлення гривневих еквівалентів після ручного коригування курсів;
- джерело кожного курсу позначено: «НБУ» (завантажений автоматично) або «✎» (введений вручну).

#### Таблиця амортизації для валютних ОВДП

Додаткові стовпці:

| Стовпець | Зміст |
|---|---|
| Курс НБУ | Офіційний курс на відповідну дату |
| Баланс поч. (грн) | Балансова вартість на початок періоду в гривнях |
| Нарах. % (грн) | Відсотковий дохід за ЕСВ у гривнях |
| КР (грн) | Курсова різниця |
| Грош. потік (грн) | Купон + номінал у гривнях |
| Баланс кін. (грн) | Балансова вартість на кінець періоду в гривнях |

#### Курсові різниці у проведеннях

- Позитивна: Дт рахунок обліку / Кт **714** «Дохід від операційної курсової різниці»
- Від'ємна: Дт **945** «Втрати від операційної курсової різниці» / Кт рахунок обліку

### 3.7 Оренда (МСФЗ 16)

**Категорія:** Оренда

**Застосування.** Підприємство є орендарем. Потрібно розрахувати зобов'язання з оренди та актив з права користування (ППКО) відповідно до МСФЗ 16 (IFRS 16).

При виборі цього типу відображається окрема панель оренди.

#### Поля введення

| Поле | Призначення |
|---|---|
| Орендний платіж, грн за період | Фіксований орендний платіж |
| Періодичність оплати | Щомісяця / щоквартально / щорічно |
| Момент оплати | На початку періоду (ануїтет-пренумерандо) або наприкінці (ануїтет-постнумерандо) |
| Ставка дисконтування, % річних | Гранична ставка запозичення орендаря або ставка, закладена в оренді (МСФЗ 16.26) |
| Початкові прямі витрати, грн | Витрати на укладення договору (МСФЗ 16.24(d)) — додаються до первісної вартості ППКО |
| Отримані стимули від орендодавця, грн | Знижки, компенсації (МСФЗ 16.24(b)) — зменшують вартість ППКО |
| Резерв на демонтаж / відновлення, грн | Оцінка витрат на демонтаж (МСФЗ 16.24(d), МСБО 37) — додається до вартості ППКО |

#### Модифікація оренди (МСФЗ 16.44–46)

Увімкніть перемикач **«Модифікація оренди»** для моделювання зміни умов:

| Поле | Призначення |
|---|---|
| Дата модифікації | Встановлюється автоматично посередині строку (можна змінити) |
| Новий орендний платіж | Порожнє — без змін |
| Нова дата закінчення | Порожнє — без змін |
| Нова ставка дисконтування | Гранична ставка на дату модифікації (обов'язкове поле) |
| Тип модифікації | «Не окрема оренда» (МСФЗ 16.45) — перерахунок зобов'язання; «Зменшення обсягу» (МСФЗ 16.46a) — пропорційне списання з визнанням прибутку або збитку |
| Відсоток зменшення обсягу | Лише для типу 16.46a — частка обсягу, що зменшується |

#### Зведення

- Кількість періодів та ставка за період.
- **Зобов'язання з оренди (ТВ)** — теперішня вартість орендних платежів.
- **ППКО** — зобов'язання + прямі витрати − стимули + резерв на демонтаж + передоплата (якщо оплата на початку періоду).
- Загальна сума платежів та загальні відсотки.

## 4. Строки та рахунки

Права картка містить поля, спільні для всіх типів інструментів.

| Поле | Призначення | Видимість |
|---|---|---|
| Дата емісії (випуску) | Дата випуску інструменту | Облігації, ОВДП |
| Дата первісного визнання | Дата початку дисконтування (дата придбання / видачі / укладення) | Усі типи |
| Дата погашення | Дата закінчення дії інструменту або оренди | Усі типи |
| Розрахунковий період | Автоматично: кількість днів та років між датами | Автоматично |
| Рахунок обліку | Випадаючий список, специфічний для кожного типу | Усі типи |

**Попередження.** Якщо строк менше 1 року — відображається повідомлення: «Дисконтування може бути несуттєвим (НП(С)БО 13 п. 6)».

**Автоматичне визначення дати погашення.** Для ОВДП: якщо заповнено поле «Термін обігу (днів)» та дату емісії — дата погашення розраховується автоматично.

### 5.1 Позначки

Три кольорові позначки у верхній частині:

| Позначка | Зміст |
|---|---|

| Строк | Тривалість у роках та днях |
| Ставка / ТВ | ЕСВ або теперішня вартість |

### 5.2 Показники

Сітка ключових показників:

| Показник | Опис |
|---|---|

| Номінал | Номінальна вартість інструменту |
| Щоденна ставка НП(С)БО | rD = (1 + r)^(1/365) − 1 |

### 5.3 Таблиця амортизації

Метод ефективної ставки. Стовпці:

| Стовпець | Зміст |
|---|---|
| Дата | Дата події |

| Баланс поч. | Балансова вартість на початок періоду |

### 5.4 Бухгалтерські проведення

Проведення згруповані за етапами:

1. 📌 **Первісне визнання** — з урахуванням комісії, дисконту або премії.
2. 📆 **Амортизація** — по роках, із зазначенням кварталів та кількості днів.
3. 🔄 **Рекласифікація** — переведення до поточної частини (для позик).
4. ✅ **Погашення** — закриття інструменту.

Формат кожного проведення: дата · дебет · кредит · сума · опис.

### 5.5 Пояснення та методологія

Розкривна панель з описом:

- формула та економічний зміст дисконтування;

- оцінка суттєвості дисконту;
- опис методу ефективної ставки;
- порівняльна таблиця «НП(С)БО та МСФЗ» (для ОВДП).

Для **оренди**: розшифровка зобов'язання, первісної вартості ППКО, амортизації, модифікації.

## 6. Додаткові можливості

### 6.1 Завантаження даних з Міністерства фінансів

1. Оберіть тип «ОВДП (гривнева)» або «ОВДП (валютна)».
2. Введіть код ISIN.
3. Натисніть **«Завантажити»**.
4. Параметри (валюта, термін, дохідність, купон, дати) заповнюються автоматично.
5. Якщо графік купонних виплат не знайдено — введіть дати вручну.

Для роботи потрібен проксі-сервер. Адреса налаштовується у розділі «Налаштування».

### 6.2 Автоматичне завантаження курсів НБУ

Для валютних ОВДП при першому розрахунку:

1. Офіційні курси НБУ завантажуються автоматично для кожної дати часової шкали.
2. Курси підставляються у відповідні поля. Джерело позначається «НБУ».
3. Будь-який курс можна змінити вручну, після чого натиснути **«Перерахувати»**.
4. Для повторного завантаження — кнопка **«Оновити курси НБУ»**.

### 6.3 Пов'язані особи

Для позик та зобов'язань:

- увімкніть перемикач **«Пов'язана особа»**;
- рахунки дисконту зміняться на 424 (дебет) / 425 (кредит) відповідно до МСБО 24 та НП(С)БО 23;
- у проведеннях та поясненнях додається примітка про вимоги до розкриття.

### 6.4 Автовизначення підтипу інструменту

Програма автоматично визначає підтип за введеними даними:

| Підтип | Умова |
|---|---|
| Безвідсоткова | Договірна ставка ≈ 0 % |
| Договірна X % (нижче ринку) | Ставка > 0, дисконт > 0,01 |
| За номіналом | Дисконт ≤ 0,01 |
| З премією | ТВ > Номінал |

### 6.5 Обробка дат

- Усі дати працюють у місцевому часовому поясі (без зсуву через переведення в UTC).
- Коректна обробка кінця місяця: 31 січня + 1 місяць = 28 (29) лютого.
- Для ОВДП: дати купонів враховуються лише після дати придбання та до дати погашення включно.
