## 1. Загальний огляд

**FinDiscounting Pro** — автономний браузерний калькулятор для:

- дисконтування фінансових інструментів (позики, зобов'язання, облігації, ОВДП);
- розрахунку оренди за МСФЗ 16 (IFRS 16);
- обчислення теперішньої вартості (PV), ефективної ставки відсотка (EIR);
- побудови таблиць амортизації методом ефективної ставки;
- генерації бухгалтерських проведень за НП(С)БО та МСФЗ.

Файл повністю автономний (HTML + CSS + JS). Працює офлайн, крім функцій завантаження з Мінфіну та курсів НБУ.

## 3. Типи інструментів

Тип обирається у випадаючому списку **«Тип фінансового інструменту»** у лівій карточці. Доступні типи згруповані за категоріями:

### 3.1 Видана позика

**Категорія**: Фінансові активи  
**Коли використовувати**: підприємство видало позику іншій стороні за ставкою нижче ринкової (або безвідсоткову).

#### Поля вводу

| Поле | Опис |
|---|---|
| **Номінальна сума** | Тіло позики (сума до повернення) |
| **Договірна ставка (%)** | Ставка за договором (0% для безвідсоткових) |
| **Ринкова / ефективна ставка (%)** | Ринкова ставка для дисконтування |
| **Комісія при придбанні** | Витрати на оформлення (включаються в PV, впливають на EIR) |
| **Пов'язана особа** | Перемикач — змінює рахунки проведень (424/425 замість 949/733, відповідно до МСБО 24 / НП(С)БО 23) |

#### Рахунки обліку
183, 377, 14 (обирається зі списку).

#### Логіка розрахунку
1. Квартальні купонні платежі = Номінал × Договірна ставка / 4.
2. PV = сума дисконтованих грошових потоків за ринковою ставкою.
3. Дисконт = Номінал − PV (якщо PV < Номінал — позика видана нижче ринку).
4. Якщо комісія > 0 — PV збільшується, EIR перераховується.

#### Проведення (НП(С)БО)
- **Первісне визнання**: Дт рахунок / Кт 311 (видача позики за PV).
- **Дисконт**: Дт 949 або 424 (пов'язана особа) / Кт рахунок.
- **Комісія**: Дт рахунок / Кт 685.
- **Щоквартально**: Дт рахунок / Кт 733 або 425 — нарахування EIR.
- **Переведення до поточної**: Дт 183 або 377 / Кт довгостроковий рахунок (останній рік).
- **Погашення**: Дт 311 / Кт рахунок.

#### Підтип «Безвідсоткова»
Автоматично визначається, якщо договірна ставка < 0,001%. У бейджі відображається «Видана позика — безвідсоткова».

### 3.2 Отримана позика / кредит

**Категорія**: Фінансові зобов'язання  
**Коли використовувати**: підприємство отримало позику або кредит за пільговою ставкою.

#### Поля вводу

| Поле | Опис |
|---|---|
| **Номінальна сума** | Сума зобов'язання до погашення |
| **Договірна ставка кредиту (%)** | Ставка за кредитним договором |
| **Ринкова ставка (%)** | Ринкова ставка для дисконтування |
| **Комісія** | Витрати на оформлення |
| **Пов'язана особа** | Перемикач — МСБО 24 |

#### Рахунки обліку
505, 55, 601.

#### Особливості
- **Рекласифікація до поточної частини** — автоматично генерується проведення переведення з довгострокового рахунка на 611 в останній рік перед погашенням.
- **Погашення** — через 611 → 311.
- Дисконт визнається як дохід (Кт 733 або 425).

---

### 3.3 Довгострокове зобов'язання

**Категорія**: Фінансові зобов'язання  
**Коли використовувати**: довгострокова торговельна або інша заборгованість, що потребує дисконтування.

#### Поля вводу
Аналогічні до «Отриманої позики»:
- Номінальна сума, договірна ставка зобов'язання, ринкова ставка, комісія, пов'язана особа.

#### Рахунки обліку
55, 685, 505.

#### Відмінності від позики
- Немає рекласифікації до поточної частини.
- Погашення — Дт рахунок / Кт 311 напряму.

### 3.4 Облігації розміщені

**Категорія**: Фінансові зобов'язання  
**Коли використовувати**: підприємство розмістило власні облігації (з купоном або без).

#### Поля вводу

| Поле | Опис |
|---|---|
| **Номінальна сума** | Номінал облігацій |
| **Купонна ставка облігації (%)** | Ставка купона за договором |
| **Ринкова ставка (%)** | Ринкова ставка для EIR |
| **Комісія** | Витрати при розміщенні (НП(С)БО 13 п.29) |
| **Дата емісії** | Видиме поле — дата випуску облігацій |

#### Рахунки обліку
521 (зобов'язання за облігаціями), 522 (премія / дисконт).

#### Проведення (НП(С)БО)
- **Первісне визнання**: Дт 311 / Кт 521 (надходження від розміщення = PV).
- **Дисконт**: Дт 522 / Кт 521 (різниця номінал − PV).
- **Премія** (якщо PV > Номінал): Дт 521 / Кт 522.
- **Комісія**: Дт 521 / Кт 685.
- **Щоквартально**: Дт 952 / Кт 521 — фінансові витрати EIR + амортизація дисконту/премії.
- Для купонних: Дт 521 / Кт 684 — нарахування купону; Дт 684 / Кт 311 — виплата.
- **Погашення**: Дт 521 / Кт 311 (за номіналом).

### 3.5 ОВДП гривнева

**Категорія**: Фінансові активи  
**Коли використовувати**: підприємство придбало облігації внутрішньої державної позики (гривневі).

Це найбільш розвинутий тип інструменту з окремою панеллю вводу, інтеграцією з Мінфіном, двома стандартами обліку та графіком купонних виплат.

#### Панель ОВДП — поля вводу

| Поле | Опис |
|---|---|
| **ISIN-код** | Ідентифікатор облігації (напр., UA4000244163). Поруч — кнопка **«Завантажити»** для автозаповнення з Мінфіну |
| **Номінал 1 облігації** | Зазвичай 1 000 грн |
| **Кількість (шт.)** | Кількість придбаних облігацій |
| **Термін обігу (днів)** | Від емісії до погашення |
| **Комісія при придбанні** | Включається в балансову вартість (НП(С)БО 12 п.29 / МСФЗ 9 B5.1.1) |
| **Купонна ставка (грн / 1 обл.)** | Сума купону за одну виплату на одну облігацію. **0** для безкупонних (дисконтних) ОВДП |
| **Номінальна дохідність НБУ (%)** | Річна дохідність з реєстру |
| **Фактична ціна 1 обл.** | Ціна придбання — основа для розрахунку EIR за НП(С)БО |
| **Справедлива вартість НБУ (грн/1 обл.)** | СВ з реєстру НБУ — основа для EIR за МСФЗ 9. Якщо не заповнено, МСФЗ-вкладка використовує фактичну ціну |

#### Summary-блок (автоматичний)
Після заповнення полів автоматично показується:
- Загальний номінал (номінал × кількість)
- Загальна сума купівлі (ціна × кількість)
- Комісія
- PV з комісією (НП(С)БО / МСФЗ)
- Дисконт або Премія
- Тип (авто): «з дисконтом» / «з премією» / «за номіналом»

#### Кнопка «Завантажити з Мінфіну»
1. Введіть ISIN-код.
2. Натисніть **«Завантажити»** (або Enter у полі ISIN).
3. Програма через проксі-сервер завантажує дані з `index.minfin.com.ua`:
   - Валюту, термін обігу, дохідність, купон, дату погашення, дату розміщення.
   - **Купонні дати** — парсяться автоматично (6 стратегій пошуку у HTML).
4. Поля автозаповнюються. Якщо купонні дати не знайдені — з'являється блок ручного введення.

#### Ручне введення купонних дат
Якщо автопарсинг не знайшов дат (або потрібно скоригувати):
1. У блоці **«Дати купонних виплат (ручне введення)»** виберіть дату.
2. Натисніть **«＋ Додати»**.
3. Дата з'явиться у списку. Для видалення натисніть **✕** поруч.
4. Дати автоматично дедуплікуються та сортуються.

#### Графік купонних виплат
Після заповнення полів відображається таблиця:
- Номер виплати, дата, кількість днів від купівлі, сума (купон × кількість облігацій).
- Показуються тільки виплати **після** дати купівлі і **до** дати погашення.

#### Два таби результатів: НП(С)БО vs МСФЗ

Для ОВДП (на відміну від інших типів) результати показуються у **двох вкладках**:

| | НП(С)БО | МСФЗ 9 (IFRS 9) |
|---|---|---|
| **База для EIR** | Фактична ціна придбання + комісія | Справедлива вартість НБУ + комісія |
| **День-1 різниця** | Включається в дисконт/премію | Визнається одразу в П&З (Дт 977 — збиток або Кт 733 — дохід) |
| **Рахунок доходу EIR** | 733 (Інші фін. доходи) | 732 (Фін. доходи від фін. активів) |
| **Нормативна база** | НП(С)БО 12, 13 | МСФЗ 9 п.5.1.1, В5.1.1 |

#### Рахунки обліку
352 (Інші поточні фінансові інвестиції) або 143 (Інвестиції пов'язаним сторонам).

#### Безкупонні (дисконтні) ОВДП
Якщо купон = 0:
- Автоматично розраховується дисконтована ціна: P = N / (1 + y × d/365).
- Єдиний грошовий потік — номінал на дату погашення.
- Купонні дати ігноруються.

### 3.6 ОВДП валютна

**Категорія**: Фінансові активи  
**Коли використовувати**: підприємство придбало валютні ОВДП (номінал в USD або EUR).

#### Відмінності від гривневої ОВДП

Все як для гривневої ОВДП, плюс:

| Додаткове поле | Опис |
|---|---|
| **Валюта ОВДП** | Вибір: $ USD або € EUR |
| **Курс НБУ на дату купівлі** | Курс перерахунку грн/валюта |
| **Номінал у гривнях** | Автоматично: Номінал × Кількість × Курс |

#### Перемикач «₴ Гривнева / $ Валютна»
Кнопка-перемикач праворуч від заголовка «ОВДП» дозволяє швидко переключитися між гривневим та валютним режимом без втрати введених даних.

#### Графік курсів НБУ по датах
Після першого розрахунку з'являється блок **«Курси НБУ по датах»**:
- Для кожної дати таймлайну (купівля, звітні дати, купони, погашення) — поле з курсом НБУ.
- Кнопка **«📥 Оновити курси НБУ»** — автоматично завантажує курси з НБУ для кожної дати.
- Кнопка **«🔄 Перерахувати»** — перераховує гривневі еквіваленти після ручного редагування курсів.
- Джерело кожного курсу позначено: «НБУ» (завантажений) або «✎» (ручний).

#### Амортизаційна таблиця для валютних ОВДП
Додаткові стовпці:
- **Курс НБУ** — на кожну дату
- **Баланс поч. (грн)**, **Нарах. % (грн)**, **КР (грн)** (курсова різниця), **Грош. потік (грн)**, **Баланс кін. (грн)**

#### Курсові різниці в проведеннях
- Позитивна КР: Дт рахунок / Кт **714** (дохід від операцій з іноземною валютою).
- Від'ємна КР: Дт **945** / Кт рахунок (витрати від операцій з іноземною валютою).

### 3.7 Оренда / МСФЗ 16

**Категорія**: Оренда  
**Коли використовувати**: підприємство є орендарем за МСФЗ 16 (IFRS 16) — потрібно розрахувати зобов'язання з оренди та право-користування-активом (ППКО / ROU asset).

При виборі цього типу відображається спеціальна **панель оренди** (замість стандартних полів).

#### Поля вводу

| Поле | Опис |
|---|---|
| **Орендний платіж (грн за період)** | Фіксований орендний платіж |
| **Періодичність оплати** | Щомісяця / Щоквартально / Щорічно |
| **Момент оплати** | На початку періоду (аннуїтет-пренумерандо) або в кінці періоду (аннуїтет-постнумерандо) |
| **Ставка дисконтування (% річних)** | Гранична ставка запозичення орендаря або ставка, закладена в оренді (МСФЗ 16.26) |
| **Початкові прямі витрати (грн)** | Витрати на укладення договору (МСФЗ 16.24(d)) — додаються до первісної вартості ППКО |
| **Отримані стимули від орендодавця (грн)** | Знижки, компенсації (МСФЗ 16.24(b)) — зменшують вартість ППКО |
| **Резерв на демонтаж / відновлення (грн)** | Оцінка витрат на демонтаж (МСФЗ 16.24(d), МСБО 37) — додається до ППКО |

#### Модифікація оренди (МСФЗ 16.44–46)

Увімкніть перемикач **«⚡ Модифікація оренди»** для моделювання зміни умов оренди:

| Поле | Опис |
|---|---|
| **Дата модифікації** | Автоматично встановлюється посередині строку оренди (можна змінити) |
| **Новий орендний платіж** | Порожнє = без змін |
| **Нова дата закінчення** | Порожнє = без змін |
| **Нова ставка дисконтування** | Гранична ставка на дату модифікації (обов'язкове поле) |
| **Тип модифікації** | «Не окрема оренда» (МСФЗ 16.45) — перерахунок зобов'язання; «Зменшення обсягу» (МСФЗ 16.46a) — пропорційне списання з прибутком/збитком |
| **% зменшення обсягу** | Тільки для типу 16.46a — частка обсягу, що зменшується |

#### Summary-блок
- К-сть періодів, ставка за період
- **Зобов'язання з оренди (PV)** — теперішня вартість платежів
- **ППКО (ROU asset)** — = зобов'язання + прямі витрати − стимули + демонтаж + передоплата (якщо на початку)
- Загальні платежі, загальні відсотки

#### Рахунки обліку

| Рахунок | Призначення |
|---|---|
| **5311** / **6111** | Зобов'язання з оренди (довгострокове / поточне) |
| **1051–1054** | ППКО (нерухомість / транспорт / обладнання / інші) |
| **1351–1354** | Знос ППКО (відповідно до типу активу) |
| **92, 93, 91, 23** | Рахунок витрат на амортизацію ППКО |

#### Вкладки результатів для оренди
Замість «НП(С)БО / МСФЗ» вкладки перейменовуються на:
- **«Зобов'язання з оренди»** — графік погашення з нарахуванням відсотків
- **«ППКО — амортизація»** — графік амортизації активу з права користування (прямолінійний метод) + зведена таблиця

#### Проведення (оренда)
1. **Первісне визнання**: Дт ППКО / Кт Зобов'язання (PV) + передоплата + прямі витрати + стимули + демонтаж.
2. **Щоперіодно**: Дт 952 / Кт Зобов'язання (відсотки EIR); Дт Зобов'язання / Кт 311 (платіж); Дт витрати / Кт знос (амортизація ППКО).
3. **Рекласифікація**: переведення поточної частини з 5311 на 6111.
4. **При модифікації**: перерахунок зобов'язання, коригування ППКО; при зменшенні обсягу — визнання прибутку/збитку.
5. **Припинення**: закриття залишку зобов'язання та ППКО.

## 4. Спільні поля — Строки та рахунки

Права карточка містить поля, спільні для всіх типів:

| Поле | Опис | Видимість |
|---|---|---|
| **Дата емісії (випуску)** | Дата випуску інструменту | Облігації, ОВДП |
| **Дата первісного визнання** | Дата, з якої починається дисконтування (дата купівлі) | Всі типи |

Для **ОВДП з терміном обігу**: якщо заповнено поле «Термін обігу (днів)» і дату емісії — дата погашення розраховується автоматично.

## 5. Результати розрахунку

Після натискання **«▶ Розрахувати»** відображається блок результатів:

### 5.1 Бейджі
Три кольорові бейджі у верхній частині:
- **Тип** — назва інструменту (або ISIN для ОВДП) з підтипом (безвідсоткова, з дисконтом, з премією)
- **Строк** — тривалість у роках та днях
- **Ставка / PV** — EIR або теперішня вартість

### 5.2 Метрики
Сітка ключових показників:

| Метрика | Опис |
|---|---|
| **Теперішня вартість (PV)** | Дисконтована вартість грошових потоків |
| **Дисконт** або **Премія** | Різниця між номіналом і PV |
| **Номінал** | Номінальна вартість |
| **Щоденна ставка НП(С)БО** | rD = (1+r)^(1/365) − 1 |
| **Щоденна ставка МСФЗ 9** | Тільки для ОВДП (може відрізнятися від НП(С)БО) |
| **⚠ Нев'язка амортизації** | Якщо «плаг» останнього рядка перевищує 1 грн — попередження |

Для **оренди**: зобов'язання, ППКО, загальні відсотки, дані модифікації.

### 5.3 Амортизаційна таблиця
Стовпці:
- **Дата** — дата події
- **Подія** — тип: звітна дата (Звіт К1 2025), купон, погашення, або квартальний лейбл
- **Баланс поч.** — залишок на початок періоду
- **Нарах. %** — відсоткова складова за метод EIR
- **Грош. потік** — купон + (номінал для останнього рядка)
- **Баланс кін.** — залишок на кінець періоду (для останнього рядка завжди 0.00)

Для **валютних ОВДП** — додаткові стовпці з гривневими еквівалентами та курсовими різницями.

### 5.4 Бухгалтерські проведення
Проведення згруповані за фазами:
1. 📌 **Первісне визнання** — з комісією, дисконтом/премією
2. 📆 **Щорічна амортизація** — згруповано по роках
3. 🔄 **Рекласифікація** — переведення до поточної частини (для позик)
4. ✅ **Погашення** — закриття інструменту

Кожне проведення: Дата | Дт рахунок | Кт рахунок | Сума | Опис.

### 5.5 Пояснення та методологія
Розкривна панель (натисніть «Пояснення та методологія ▸» для розгортання):

- **Формула та економічний зміст** — чому необхідне дисконтування
- **Нормативна база** — посилання на пункти стандартів
- **Суттєвість дисконту** — якісна оцінка
- **Метод ефективної ставки** — опис EIR
- **Порівняння НП(С)БО vs МСФЗ** (для ОВДП) — таблиця відмінностей

## 6. Спеціальні функції

### 6.1 Завантаження з Мінфіну
1. Оберіть тип «ОВДП (гривнева)» або «ОВДП (валютна)».
2. Введіть ISIN-код у поле (напр., `UA4000244163`).
3. Натисніть **«Завантажити»**.
4. Дані (валюта, термін, дохідність, купон, дати) автозаповняться.
5. Якщо купонних дат не знайдено — введіть їх вручну.

> **Потрібен проксі-сервер** — за замовчуванням використовується Cloudflare Worker. URL можна змінити в Налаштуваннях.

### 6.2 Автозавантаження курсів НБУ
Для валютних ОВДП при першому розрахунку:
1. Автоматично завантажуються курси НБУ на кожну дату таймлайну.
2. Курси підставляються у поля. Джерело позначається «НБУ».
3. Можна змінити будь-який курс вручну, натиснути «🔄 Перерахувати».
4. Для повторного завантаження — кнопка «📥 Оновити курси НБУ».

### 6.3 Пов'язані особи
Для позик і зобов'язань (loan_out, loan_in, liab):
- Увімкніть перемикач **«Пов'язана особа»**.
- Рахунки дисконту зміняться на 424 (Дт) / 425 (Кт) відповідно до МСБО 24 / НП(С)БО 23.
- В проведеннях та поясненнях додається примітка про розкриття.

### 6.4 Автовизначення підтипу
Калькулятор автоматично визначає підтип інструменту:
- **Безвідсоткова** — договірна ставка ≈ 0%
- **Договірна X% (нижче ринку)** — ставка > 0, але дисконт > 0.01
- **За номіналом** — дисконт ≤ 0.01
- **З премією** — PV > Номінал

### 6.5 Обробка дат
- Усі дати працюють у **локальному часовому поясі** (без UTC-зсувів).
- Функція `addM` коректно обробляє кінець місяця (31 січня + 1 місяць = 28/29 лютого).
- Для ОВДП: дати купонів фільтруються — тільки після дати купівлі та до дати погашення включно.

## Швидкий старт — покрокова інструкція

### Приклад 1: Безвідсоткова позика

1. Тип → **«Видана позика»**
2. Номінальна сума → `100 000`
3. Договірна ставка → `0`
4. Ринкова ставка → `18`
5. Дата визнання → `2025-01-01`
6. Дата погашення → `2028-01-01`
7. Натисніть **«▶ Розрахувати»**

### Приклад 2: Купонна ОВДП

1. Тип → **«ОВДП (гривнева)»**
2. ISIN → введіть код, натисніть **«Завантажити»**
3. Перевірте заповнені поля, при потребі скоригуйте ціну купівлі
4. Введіть **Справедливу вартість НБУ** (для вкладки МСФЗ)
5. Дата купівлі → фактична дата придбання
6. Натисніть **«▶ Розрахувати»**
7. Переключайте вкладки **НП(С)БО / МСФЗ** для порівняння

### Приклад 3: Оренда офісу

1. Тип → **«Оренда (МСФЗ 16)»**
2. Орендний платіж → `15 000`
3. Періодичність → «Щомісяця»
4. Момент оплати → «На початку періоду»
5. Ставка → `14`
6. Дата початку → `2025-01-01`, дата закінчення → `2028-01-01`
7. ППКО рахунок → `1051 — нерухомість`
8. Натисніть **«▶ Розрахувати»**
