1. Призначення програми

FinDiscounting Pro — інструмент для дисконтування фінансових інструментів та розрахунку оренди. Програма виконує:

  • обчислення теперішньої вартості (ТВ) грошових потоків;
  • визначення ефективної ставки відсотка (ЕСВ);
  • побудову таблиць амортизації методом ефективної ставки;
  • формування бухгалтерських проведень за НП(С)БО та МСФЗ;
  • порівняння облікових підходів (НП(С)БО / МСФЗ 9) для ОВДП.

Файл працює автономно у браузері. Мережа потрібна лише для завантаження даних з Міністерства фінансів та курсів НБУ.

Нормативна база
НП(С)БО 10, 11, 12, 13, 28 · МСФЗ 9, 16 · МСБО 32, 37, 39

Містить вибір типу інструменту та відповідні поля введення. Залежно від обраного типу відображається одна з трьох панелей:

3. Типи фінансових інструментів

Тип обирається у випадаючому списку, згрупованому за трьома категоріями: Фінансові активи, Фінансові зобов'язання, Оренда.

3.1 Видана позика

Фінансові активи

Підприємство видало позику за ставкою нижче ринкової або безвідсотково. Різниця між номіналом і теперішньою вартістю визнається витратами (або внеском до капіталу пов'язаної особи).

Поля введення

ПолеПризначення
Номінальна сумаОсновна сума позики (тіло боргу)
Договірна ставка, %Відсоткова ставка за договором. Для безвідсоткових — 0
Ринкова / ефективна ставка, %Ставка, за якою дисконтуються грошові потоки
Комісія при видачіВключається до балансової вартості; змінює ЕСВ (НП(С)БО 12 п. 29, МСФЗ 9 В5.1.1)
Пов'язана особаПеремикач. Змінює рахунки: 424/425 замість 949/733 (МСБО 24, НП(С)БО 23)

Рахунки обліку: 183 · 377 · 14

Порядок розрахунку

  1. Квартальні відсоткові платежі = Номінал × Договірна ставка / 4.
  2. Теперішня вартість = сума дисконтованих грошових потоків за ринковою ставкою.
  3. Дисконт = Номінал − ТВ.
  4. Якщо комісія > 0 — ТВ збільшується, ЕСВ перераховується.

3.3 Довгострокове зобов'язання

Фінансові зобов'язання

Довгострокова торговельна або інша заборгованість, що потребує дисконтування. Поля введення аналогічні до отриманої позики: номінальна сума, договірна ставка, ринкова ставка, комісія, пов'язана особа.

Рахунки обліку: 55 · 685 · 505

Відмінності від позики

  • Рекласифікація до поточної частини не передбачена.
  • Погашення — Дт рахунок / Кт 311 напряму.

3.5 ОВДП (гривнева)

Фінансові активи

Підприємство придбало облігації внутрішньої державної позики, номіновані в гривні. Це найбільш розвинутий тип інструменту: окрема панель введення, завантаження даних з Міністерства фінансів, подвійний розрахунок за НП(С)БО та МСФЗ 9, графік купонних виплат.

Зведення (автоматичне)

Після заповнення полів відображається: загальний номінал, загальна сума придбання, комісія, ТВ з комісією (НП(С)БО / МСФЗ), дисконт або премія, тип (автовизначення).

Завантаження даних з Міністерства фінансів

  1. Введіть код ISIN.
  2. Натисніть «Завантажити» (або Enter у полі ISIN).
  3. Програма через проксі-сервер отримує: валюту, термін обігу, дохідність, купон, дату погашення, дату розміщення, графік купонних виплат.
  4. Якщо графік купонних виплат не знайдено — введіть дати вручну.

Ручне введення дат купонних виплат

У блоці «Дати купонних виплат» оберіть дату, натисніть «Додати». Для видалення — «✕» поруч. Дати автоматично перевіряються на дублювання та сортуються хронологічно.

3.6 ОВДП (валютна)

Фінансові активи

ОВДП, номіновані в іноземній валюті (долар США або євро). Усе як для гривневої ОВДП, плюс додаткові поля:

ПолеПризначення

Перемикач «Гривнева / Валютна»

Кнопка-перемикач праворуч від заголовка «ОВДП» дозволяє переключитися між режимами без втрати введених даних.

Розклад курсів НБУ по датах

Після першого розрахунку з'являється блок «Курси НБУ по датах»: для кожної дати часової шкали — окреме поле з курсом. Кнопка «Оновити курси НБУ» — автоматичне завантаження. Кнопка «Перерахувати» — оновлення після ручного коригування. Джерело: «НБУ» (автоматичне) або «✎» (ручне).

Згруповані за етапами: первісне визнання, амортизація (по роках), рекласифікація, погашення. Формат: дата · дебет · кредит · сума · опис.

Пояснення та методологія

Розкривна панель: формула, нормативна основа, оцінка суттєвості, опис методу ЕСВ, порівняння НП(С)БО та МСФЗ (для ОВДП).

6. Додаткові можливості

Завантаження даних з Міністерства фінансів

  1. Оберіть тип «ОВДП (гривнева)» або «ОВДП (валютна)».
  2. Введіть код ISIN, натисніть «Завантажити».
  3. Параметри заповнюються автоматично.
  4. Якщо графік купонних виплат не знайдено — введіть дати вручну.

Для роботи потрібен проксі-сервер. Адреса налаштовується у розділі «Налаштування».

Автоматичне завантаження курсів НБУ

Для валютних ОВДП при першому розрахунку офіційні курси НБУ завантажуються автоматично для кожної дати часової шкали. Будь-який курс можна змінити вручну. Для повторного завантаження — кнопка «Оновити курси НБУ».

Пов'язані особи

Для позик та зобов'язань: увімкніть перемикач «Пов'язана особа». Рахунки дисконту зміняться на 424/425 відповідно до МСБО 24 та НП(С)БО 23.

7. Налаштування

Натисніть «Налаштування» у заголовку. Доступний параметр — адреса проксі-сервера для завантаження даних ОВДП з Міністерства фінансів. У панелі також наведена інструкція зі створення власного проксі-сервера. Налаштування зберігаються у сховищі браузера.

8. Друк

Натисніть «Друк» у заголовку. При друці обидві вкладки (НП(С)БО та МСФЗ) виводяться на окремих сторінках у чорно-білому режимі. Для збереження у PDF: оберіть «Зберегти як PDF» замість принтера.

9. Приклади

Приклад 1. Безвідсоткова позика

  1. Тип → «Видана позика»
  2. Номінальна сума → 100 000
  3. Договірна ставка → 0
  4. Ринкова ставка → 18
  5. Дата визнання → 01.01.2025, дата погашення → 01.01.2028
  6. Натисніть «Розрахувати»

Приклад 2. Купонна ОВДП

  1. Тип → «ОВДП (гривнева)»
  2. Код ISIN → введіть код, натисніть «Завантажити»
  3. Перевірте заповнені поля; за потреби скоригуйте ціну придбання
  4. Введіть справедливу вартість НБУ (для вкладки МСФЗ 9)
  5. Дата придбання → фактична дата операції
  6. Натисніть «Розрахувати», перемикайте вкладки НП(С)БО / МСФЗ

Приклад 3. Оренда офісного приміщення

  1. Тип → «Оренда (МСФЗ 16)»
  2. Орендний платіж → 15 000, періодичність → «Щомісяця», момент → «На початку періоду»
  3. Ставка дисконтування → 14
  4. Дата початку → 01.01.2025, дата закінчення → 01.01.2028
  5. Рахунок ППКО → 1051 — нерухомість
  6. Натисніть «Розрахувати»
